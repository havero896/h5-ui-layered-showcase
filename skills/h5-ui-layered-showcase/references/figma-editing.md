# Figma 实施要点

只在实际需要修改 Figma 时阅读。先使用当前环境提供的 Figma 连接及其必需的工具说明；以现场节点和属性为准，不复用案例中的节点 ID。

## 复制与保护

1. 确认目标文件、页面、原画板和新展示画板的位置。读取原稿层级、可见内容、裁切属性和文字；若用户提供 project context，也读其当前版本。
2. 在原稿旁创建独立展示框架。复制或克隆需要的节点，再在副本中拆层；不要为了方便而改原稿的裁切、透明度、字体或结构。用户在展示稿里手调过的层优先局部修改，避免整板重建。
3. 每次修改前重读目标节点的当前属性。对原稿做前后轻量核对：画板尺寸、直属层数、关键文案或截图；对展示稿核对真实文本、顺序、可编辑节点和视觉结果。

## 倾斜

当水平边必须保持与海报平行时，用仿射变换统一处理整个模块。Figma 的二维变换可写作：

    [[1, k, tx],
     [0, s, ty]]

水平单位向量仍为 (1, 0)，竖直单位向量变为 (k, s)。若希望两轴原长度不变，可用 k = sin(θ)、s = cos(θ)，θ 取自参考图的视觉幅度；不要把 8° 等某个案例值当通用参数。模块内部原排版保持不变。倾斜前后同时核对图片、进度、按钮底、图标及文字；若有部件不应倾斜，按用户说明单独成层。

若工具提供 Skew 功能，可用它完成同样的整体倾斜。避免对每个子元素手动填写不同偏移，尤其是按钮文字和半圆进度条。

## 渐隐与裁切

- 先看原画板实际裁切位置。例如按钮在手机框外只露一部分时，展示稿可保留完整按钮结构，并让框外部分逐渐透明；渐隐方向与裁切侧一致。
- 在 Figma 中做局部 alpha mask 时，把遮罩和内容放在独立容器中；遮罩必须在被遮内容之前。创建组后重新检查子节点顺序，不能假定组函数保留传入顺序。设置遮罩类型后，用截图确认底、图标和文字一起渐隐。
- 主视觉边缘通常用较缓的透明过渡；原本不出现在画面里的按钮外段可更强。下一屏预告按垂直方向淡出。每种淡出都检查透明端是否仍留有清楚的直线边界。
- 不拉伸图片去掩盖边界。优先调整遮罩范围、渐变停靠点或层叠顺序。

## 文字与引线

- 从原画板复制真实文案。新写的说明也要匹配用户已定的字族、字重、字号、行距和标注间距。字框宽度按真实字体测量；若远程环境无该字体，在本地 Figma 设置并核对。别把文字转轮廓。
- 用同一坐标系计算折线起点、圆角转折和终点。水平起笔，再以平滑曲线转向目标；把矢量路径的本地坐标和节点 x/y 对齐，避免重复偏移。终点圆点取标准圆形，圆心落在线端。检查线不穿过标题、说明或玻璃轮廓的错误位置。
- 适合管理时，把一个标注的编号、标题、两行说明、折线和圆点编入同一语义组；若跨组会改变坐标，重组后截图核对。

## 两类验收

结构验收：原稿不变；展示图层按语义分组；文字、形状、蒙版仍可编辑；该同倾斜的元素保持同一变换；遮罩顺序正确。

视觉验收：全画板看焦点与留白；局部放大看字、按钮、圆点、玻璃描边和透明边界。任一处硬裁、错位、线端偏移或文字压门，修正后再看一次。
