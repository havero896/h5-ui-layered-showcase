# H5 UI 分层展示 Skill

把已有的 H5 或移动端 Figma 页面，整理为可编辑的作品集分层展示画板。Skill 会从原稿读取真实内容，按页面结构安排纵向倾斜、玻璃层级、渐隐和说明标注，并检查原稿保护与图层可编辑性。

## 使用前准备

- 最好提供可编辑的 Figma 原画板及编辑权限；只提供截图时，Skill 会先给出可执行的分层方案，并说明哪些内容需要原素材才能保持可编辑。
- 可附参考图、展示比例、字体规范，以及明确要求倾斜或不倾斜的元素。
- 若同一文件中已有手调过的展示稿，请指出它，方便沿用字号与间距。

## 安装与调用

将整个 h5-ui-layered-showcase 文件夹放入你使用的 Agent 的 Skills 目录。在 Codex 中，个人 Skill 可放在 ~/.codex/skills/。具体路径以所用产品的当前文档为准。

示例提示词：

> 使用 $h5-ui-layered-showcase，把我当前 Figma 的「原画板名称」制作成旁边一张可编辑的作品集分层展示。原画板不动。参考我附的图片，保留原文案与模块布局；把需要倾斜、渐隐的部分按实际层级处理，最后检查引线、字体和裁切边界。

本 Skill 负责设计与 Figma 展示稿，不负责把页面开发成可运行的 H5 网站。
